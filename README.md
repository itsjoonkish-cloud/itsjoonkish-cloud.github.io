# itsjoonkish-cloud.github.io

쭌키의 위클리 트렌드 리포트(주간 마케팅 트렌드 클리핑 뉴스레터)의 공개 안내 사이트.

Google Cloud OAuth 동의 화면(브랜딩)에 필요한 홈페이지·개인정보처리방침·이용약관을
제공하기 위해 만들었다.

- `index.html` — 도구 소개, Gmail 권한을 쓰는 이유
- `privacy.html` — 개인정보처리방침 (Google 사용자 데이터 처리 고지, Limited Use 포함)
- `terms.html` — 이용약관
- `style.css` — 공통 스타일

뉴스레터 파이프라인 본체는 비공개 저장소 `weekly-clipping-agent` 에 있다.
