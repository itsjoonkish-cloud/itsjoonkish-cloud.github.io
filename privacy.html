소개로 돌아가기 이용약관

1. 이 도구의 성격

쭌키의 위클리 트렌드 리포트(이하 "이 도구")는 마케팅 트렌드 뉴스와 공개 리포트를 모아 이메일 뉴스레터로 보내는 개인용 자동화 도구입니다. 일반에 공개된 서비스가 아니며 회원가입 기능이 없습니다. 운영자는 joooon.k@gmail.com 입니다.

2. 요청하는 Google 권한

이 도구는 Google 계정에 대해 https://www.googleapis.com/auth/gmail.send 권한 하나만 요청합니다. 이 권한은 메일을 보내는 것만 허용합니다. 받은편지함을 읽거나 검색하거나 메일을 수정 또는 삭제하는 권한은 요청하지 않으며, 기술적으로도 할 수 없습니다.

권한을 승인하는 사람은 운영자 본인 한 명입니다. 뉴스레터를 받는 동료들은 Google 계정을 연결하지 않으며 이 도구에 로그인하지도 않습니다.

3. 접근하고 사용하는 정보

  • 메일 발송 권한 토큰 — 운영자가 승인할 때 Google이 발급하는 인증 토큰입니다. 뉴스레터를 보낼 때 발신 권한을 증명하는 용도로만 씁니다.
  • 발신 계정 주소 — 뉴스레터의 보낸사람으로 표시됩니다.
  • 수신자 이메일 주소 — 운영자가 직접 입력해 둔 고정 목록입니다. Google에서 가져오지 않으며 주소록에 접근하지 않습니다.

이 도구는 Gmail의 메일 내용, 첨부파일, 주소록, 캘린더, 드라이브 등 다른 어떤 Google 데이터에도 접근하지 않습니다.

4. 정보를 저장하는 방식

인증 토큰과 수신자 목록은 운영자가 관리하는 실행 환경의 환경변수, 그리고 운영자 개인 컴퓨터의 설정 파일에만 저장됩니다. 외부 데이터베이스나 제3자 서버로 전송하지 않습니다. 발송된 뉴스레터 본문과 기사 목록은 공개된 뉴스 제목과 링크로만 이루어져 있으며 운영자의 비공개 저장소에 기록으로 남습니다.

5. 정보를 공유하지 않습니다

이 도구는 Google 사용자 데이터를 어떤 제3자에게도 판매하거나 양도하거나 공유하지 않습니다. 광고에 사용하지 않고, 인공지능 모델의 학습 데이터로 제공하지 않으며, 분석 업체나 데이터 브로커에 넘기지 않습니다.

6. Google API 서비스 사용자 데이터 정책

이 도구가 Google API로부터 받은 정보를 사용하고 다른 곳에 전달하는 행위는 Google API 서비스 사용자 데이터 정책을 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

7. 보관 기간과 권한 철회

인증 토큰은 운영자가 권한을 철회하거나 토큰을 폐기할 때까지만 보관합니다. 운영자는 언제든지 Google 계정 권한 페이지에서 이 도구의 접근 권한을 삭제할 수 있고, 삭제하면 저장된 토큰은 즉시 무효가 되어 더 이상 메일을 보낼 수 없게 됩니다. 뉴스레터 수신을 원하지 않는 동료는 운영자에게 알리면 목록에서 제외됩니다.

8. 변경 안내

이 방침이 바뀌면 이 페이지의 내용과 상단 수정일을 갱신합니다.

Privacy Policy (English)

Scope of access

Weekly Clipping is a personal automation tool. It requests exactly one Google permission, https://www.googleapis.com/auth/gmail.send, which allows sending mail only. It cannot and does not read, search, modify, or delete mail, and it does not access contacts, Calendar, Drive, or any other Google data. Only the operator authorizes the app; newsletter recipients never connect a Google account.

What is used and stored

The app uses the OAuth token issued at authorization solely to send the newsletter, together with the sender address and a fixed recipient list entered manually by the operator. Tokens and the recipient list are stored only in the operator's own execution environment variables and local configuration file. Nothing is sent to an external database or third-party server.

No sharing

Google user data is never sold, transferred, or shared with third parties, never used for advertising, and never used to train AI models.

Limited Use

Weekly Clipping's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revocation

The token is retained until the operator revokes access at Google account permissions, after which it stops working immediately. Recipients may ask the operator to be removed from the list at any time.
